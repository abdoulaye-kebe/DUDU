Politique de Confidentialité

Dernière mise à jour : Février 2026

Chez DUDU, nous prenons la protection de vos données personnelles très au sérieux. Cette politique explique quelles données nous collectons, comment nous les utilisons et comment nous les protégeons.

1. Données Collectées

Nous collectons les données suivantes :

  • Informations d'identification : Nom, prénom, numéro de téléphone, email
  • Données de localisation : Position GPS pour le service de transport
  • Données de paiement : Informations de carte bancaire (cryptées)
  • Historique des courses : Trajets effectués, montants payés
  • Données techniques : Type d'appareil, système d'exploitation, adresse IP

2. Utilisation des Données

Vos données sont utilisées pour :

  • Fournir le service de transport (mise en relation avec les chauffeurs)
  • Traiter les paiements
  • Améliorer la qualité du service
  • Assurer la sécurité des utilisateurs
  • Envoyer des notifications liées au service
  • Respecter nos obligations légales

3. Partage des Données

Nous partageons vos données uniquement avec :

  • Les chauffeurs : Nom, photo de profil, point de départ et destination
  • Prestataires de paiement : Pour traiter les transactions
  • Services d'urgence : En cas de situation d'urgence
  • Autorités légales : Si requis par la loi

Nous ne vendons jamais vos données à des tiers.

4. Protection des Données

Nous mettons en œuvre des mesures de sécurité robustes :

  • Cryptage SSL/TLS pour toutes les communications
  • Cryptage des données sensibles (paiement, localisation)
  • Accès restreint aux données personnelles
  • Audits de sécurité réguliers
  • Serveurs sécurisés avec pare-feu

5. Conservation des Données

Nous conservons vos données aussi longtemps que nécessaire pour fournir le service et respecter nos obligations légales. Vous pouvez demander la suppression de vos données à tout moment.

6. Vos Droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier vos données si elles sont inexactes
  • Supprimer votre compte et vos données
  • Limiter le traitement de vos données
  • Vous opposer au traitement de vos données
  • Recevoir une copie de vos données (portabilité)

Pour exercer ces droits, contactez-nous à : privacy@dudugroup.sn

7. Cookies

Nous utilisons des cookies pour améliorer votre expérience. Vous pouvez désactiver les cookies dans les paramètres de votre navigateur, mais cela peut affecter certaines fonctionnalités.

8. Données de Localisation

Nous collectons votre position GPS uniquement lorsque vous utilisez l'application. Vous pouvez désactiver la localisation dans les paramètres de votre appareil, mais cela empêchera l'utilisation du service de transport.

9. Mineurs

Notre service est destiné aux personnes de 18 ans et plus. Nous ne collectons pas sciemment de données auprès de mineurs.

10. Modifications

Nous pouvons modifier cette politique de confidentialité à tout moment. Les modifications importantes seront notifiées via l'application ou par email.

Votre confiance est importante pour nous. Nous nous engageons à protéger vos données personnelles et à respecter votre vie privée. Si vous avez des questions ou des préoccupations, n'hésitez pas à nous contacter.
